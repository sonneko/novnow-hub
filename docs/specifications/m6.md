# 仕様書: M6 マルチプラットフォーム（Tauri・PWA）

本書は novnow-hub の M6（マルチプラットフォーム）におけるユーザーから見える振る舞いを定義する。コードの実装情報は含まず、実装設計は設計書に委ねる。Phase 1（外部基盤を土台とした提供形態）のスコープとし、M5 で導入した novnow 特化機能の上にマルチプラットフォーム対応を載せる。

---

## 1. 目的とスコープ

### 1.1 目的とスコープ

M6 の目的は、Web アプリを Tauri によるデスクトップアプリとして配布し、PWA 化によるオフライン閲覧を実現し、セッションを安全に保管してセットアップ URL をカスタムスキームで受信できるようにすることである。M6 の完了条件は「デスクトップアプリがセットアップ URL 経由で作品を開き、Web と同一の操作体系であること」である。

スコープ内：Tauri v2 によるデスクトップビルド（Windows／macOS／Linux）と配布パイプライン、PWA 化（manifest、オフラインシェル、読者ビューのオフライン閲覧）、Tauri secure storage へのセッション保管とカスタムスキームでのセットアップ URL 受信、インストーラ署名またはストア配布の方式決定と実装。

スコープ外：M7 で実施する本番デプロイ、外形監視、バックアップ、鍵ローテーション、セキュリティレビュー、依存ライセンスの棚卸し、セルフホストガイド等の運用・公開準備。

---

## 2. Tauri v2 デスクトップビルド

### 2.1 デスクトップアプリの提供

Web アプリ（Astro + Svelte + TypeScript）と同一のコードベースを Tauri v2 でデスクトップアプリとしてパッケージングし、Windows／macOS／Linux で動作させる。見た目と操作は Web 版と共通とする。

### 2.2 配布パイプライン

デスクトップアプリのビルドと配布をパイプラインで自動化する。ビルド成果物は各プラットフォーム向けに生成され、配布可能な形式で出力される。

---

## 3. PWA 化

### 3.1 PWA マニフェストとオフラインシェル

PWA マニフェスト（manifest）を提供し、ブラウザからアプリとしてインストールできるようにする。オフラインシェルにより、ネットワークが不安定な環境でもアプリのシェル部分を表示できる。

### 3.2 読者ビューのオフライン閲覧

読者ビュー（公開ページの本文）をオフラインで閲覧できる。キャッシュ戦略により、既に読んだ公開ページの本文をオフラインでも表示できる。

---

## 4. セッション保管とセットアップ URL 受信

### 4.1 Tauri secure storage へのセッション保管

デスクトップアプリでは、セッション情報（アクセストークン・更新トークン）を Tauri secure storage（Keychain / Credential Manager 等）に保管する。ブラウザ版とは異なり、メモリのみに依存せず、アプリ再起動後もセッションを維持できる。

### 4.2 カスタムスキームでのセットアップ URL 受信

デスクトップアプリは OS のカスタムスキームでセットアップ URL を受信し、作品の取得 → ローカルへの配置 → novnow プロジェクトとしての初期化検証 → エディタを開くを自動で行う。URL ひとつでセットアップ済みの作品をアプリで開けること。

---

## 5. インストーラ署名およびストア配布

### 5.1 インストーラ署名またはストア配布の方式

デスクトップアプリのインストーラに署名を付与するか、ストア配布の方式を決定し実装する。署名により、ユーザーはインストーラの出所を検証できる。

### 5.2 配布方式の決定

Phase 1 では、インストーラ署名またはストア配布のいずれかを既定の配布方式とし、利用者が安全にデスクトップアプリをインストールできるようにする。

---

## 6. 非機能要件

### 6.1 セキュリティ

セッション情報はクライアント側の安全なストレージに保管し、平文で露出しない。インストーラ署名により改ざんを防ぐ。GitHub へのアクセスはアダプター層の背後に隠し、API 契約・フロントエンド・利用者体験には GitHub の概念を漏らさない。

### 6.2 性能と可用性

デスクトップアプリの起動とオフライン閲覧は、ネットワークに依存せず動作する。PWA のキャッシュ戦略により、読者ビューのオフライン閲覧を実現する。
