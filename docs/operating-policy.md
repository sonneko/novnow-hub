# 運営ポリシー（M7 §5.2）

novnow-hub 公開インスタンスの運営ポリシー。公開基準・削除基準・著作権対応を定める。

## 公開基準

novnow-hub の公開インスタンスは、以下の条件を満たす作品を公開対象とする。

1. **novnow 形式の軽量検証を通過していること**：`project.toml`（`schema_version = 2` または省略）・`characters.md`・`words.md`・`materials/index.json`・`plots/all.cnov`・`contents/` ディレクトリ・`plots/` ディレクトリが揃い、文字コードが UTF-8 であること（M3 の novnow 軽量検証、契約: `REF:api/openapi.yaml` の `verifyProject`）。
2. **公開範囲が `public` であること**：保管単位の `visibility` が `Public` に設定されていること（契約: `ProjectVisibility`）。
3. **権限判定を通過していること**：公開フロー（`POST /projects`）は認証必須（GitHub OAuth + PKCE）。認証済みの利用者のみが作品を公開できる（設計: `REF:docs/designs/m3.md`）。

## 削除基準

以下の条件に該当する作品・プロジェクトは、公開から削除（取り下げ）の対象とする。

1. **利用者からの削除請求**：作品の作者が `DELETE` 相当の操作（保管単位の取り下げ）を請求した場合。
2. **著作権侵害の申し立て**：第三者からの著作権侵害申し立てがあり、事実と認められる場合。削除前に著作者・権利者への通知と反論の機会を与えるものとする。
3. **法令・公序良俗に反する内容**：違法なコンテンツ、他者への誹謗中傷、個人情報の不適切な公開等が含まれる場合。
4. **サービス運用上の理由**：サーバー負荷・セキュリティ上の理由等、運営者がやむを得ず削除を判断した場合。

削除時は保管単位を取り下げ、中間状態（保管単位・ファイル・公開 URL）を残さないようクリーンアップを行う（M3 の公開フローにおけるクリーンアップ方針、判断: `REF:docs/handoff.md` §4 判断 6(c)）。

## 著作権対応

1. **著作権の帰属**：各作品の著作権はその著作者に帰属する。novnow-hub は作品をホストするのみであり、著作権を譲渡・譲受しない。
2. **ライセンスの表示**：作品の `project.toml` に記載されたライセンス（`cc-by`、`cc0`、`cc-by-sa` 等、契約の列挙値）を公開ページに表示し、利用者がライセンスを確認できるようにする。
3. **著作権侵害への対応**：著作権侵害の申し立てを受けた場合、削除基準 §2 に従い対応する。申し立て内容・対応履歴を記録・保管する。
4. **引用・転載の制限**：公開ページに掲載された作品の本文を、ライセンス条件を満たさずに第三者が転載・複製することは許諾されない。

## その他

- 本ポリシーは公開インスタンスの運営者向けであり、セルフホストする利用者は独自にポリシーを定めて運用してもよい。
- 本ポリシーの変更は、`docs/history.md` に追記専用の記録として残す。
