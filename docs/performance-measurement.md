## 未測定項目と理由

### LCP（Largest Contentful Paint）

**未測定**。理由：サンドボックスに Chrome／Chromium および Lighthouse がインストールされておらず、ブラウザベースの LCP 計測が行えない。ローカルプレビューに対する Lighthouse 計測も不可。

代替として、ビルド出力の HTML ファイルサイズ（1 ページあたり 8–9.6 KB）と静的サイト生成（SSG）による事前レンダリングを指標とする。HTML が極めて軽量で CDN キャッシュ前提であるため、国内モバイル回線での LCP は 2 秒以内を達成できると**推定**する（実測ではない）。

### hub API p95 応答時間

**未測定**。理由：サンドボックスに Rust ツールチェーン（cargo/rustc）がインストールされておらず、サーバー（`server/` crate）のビルド・起動が行えない。API レイテンシの計測が不可。

代替として、Axum ベースの軽量 HTTP サーバー、読み取り系エンドポイント（`GET /api/v1/meta` 等）は認証不要、インメモリストアを使用するため、サーバ処理時間は p95 で 200 ms 以内を達成できると**推定**する（実測ではない）。

### 月間可用性

**未測定**。理由：本番環境（Cloudflare Workers + D1）が未デプロイであり、外形監視の実績データが存在しない。アカウント側での Cloudflare アカウント・Worker・D1 データベース・ドメイン・Secrets の有効化が必要。

外形監視の仕組みは `REF:.github/workflows/monitoring.yml`（5 分間隔、`GET /api/v1/meta` と公開ページの 200 応答を検証）として整備済み。本番デプロイ後の実測で可用性を検証する。

## コスト試算（推定）

### 構成要素と無料枠

| サービス | 無料枠 | 有償枠 | 想定月額 |
|---|---|---|---|
| GitHub Actions | パブリックリポジトリ無料 | － | ¥0 |
| Cloudflare Workers | 100,000 リクエスト/日 | $5/月（1,000 万リクエスト/月） | ¥0〜¥750 |
| Cloudflare D1 | 5GB ストレージ、100 万読み取り/日 | $5/月（追加ストレージ等） | ¥0〜¥750 |
| Cloudflare R2（必要に応じて） | 10GB ストレージ、100 万オペレーション/月 | 従量課金 | ¥0〜¥500 |
| ドメイン | － | 年間約 ¥1,000〜¥2,000 | 約 ¥100〜¥200/月 |

### 合計見積もり

**月額約 ¥0〜¥2,000**（ドメイン費を含む）

GitHub Actions はパブリックリポジトリで無料、Cloudflare Workers/D1 は無料枠で十分に収まる見込み。定時実行（cron）は外形監視の 5 分間隔 1 ジョブのみであり、従量課金の暴走リスクは低い。

### 結論

月額数千円以下というコスト制約に**収まると推定**する（実績値ではない）。実際のコストは本番デプロイ後の使用量に依存し、アカウント側での監視が必要。

## 改善案（実装は後続タスク）

1. **LCP 実測**: Chrome/Lighthouse を導入し、ローカルプレビューおよび本番環境で LCP を計測する。
2. **API p95 実測**: Rust ツールチェーンをインストールし、サーバーをビルド・起動して API レイテンシを計測する。
3. **可用性実測**: 本番環境（Workers + D1）にデプロイし、外形監視ワークフローの実績データを収集する。
4. **コスト実績**: 本番デプロイ後の実際の使用量に基づき、コストを確定する。
